# Legacy Reference

This folder is a legacy snapshot that is kept in the repo for reference.

If you want to run the current Smart PC Builder demo, use the instructions in the root [README.md](../README.md).

## Current Run Path

From the repository root:

```bash
npm install
cd server
npm install
npm start
```

Then open a second terminal at the repository root:

```bash
npm run dev
```

The active demo uses the root app, SQLite backend, and seeded smart catalog. This nested folder is not the main entry point for the current demo.
